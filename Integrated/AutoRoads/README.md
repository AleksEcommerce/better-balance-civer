# Автоматическая прокладка дорог — маршрут по одному гексу

Функция встроена в Better Balance Civer. Отдельный Auto Build Road (Steam 3592659261) должен быть выключен. Его файлы не изменяются. Источник первоначальной идеи: Auto Build Road: Builders and Military Engineers, Genever — https://steamcommunity.com/sharedfiles/filedetails/?id=3592659261

## Использование

1. Выбрать строителя или военного инженера и нажать кнопку дороги в панели юнита.
2. Выбрать конечную клетку левой или правой кнопкой мыши. Escape отменяет выбор. Модальное окно выбора перехватывает обычные приказы движения WorldInput/CQUI.
3. Контроллер сохраняет цель. На каждом ходу он запрашивает путь, затем разрешает и отправляет обычную команду движения только на один соседний гекс. После прибытия прокладывается участок и расходуется оставшееся движение.
4. Если на текущей клетке нет требуемой дороги, сначала строится она без перемещения. Это не позволяет оставлять разрывы в маршруте.
5. Повторное нажатие кнопки отменяет маршрут. Для ручного движения или включения сторонней автоматизации того же строителя сначала отменить маршрут дороги.

Строитель платит 2 золота за новую/улучшенную клетку дороги; инженер — 1 железо и 1 уголь за железную дорогу. Для инженера проверяется «Паровая машина». При нехватке ресурсов или заблокированном пути движение по маршруту приостанавливается, повторная попытка — на следующем ходу. Причина показывается в подсказке. Дорога на текущей клетке достраивается перед дальнейшим перемещением. На готовых участках всё равно выполняется лишь один соседний переход за ход; ресурсы повторно не тратятся.

Цель, последний обработанный ход и разрешённый шаг хранятся в свойствах юнита. Игровая часть не использует локального игрока; команды движения и выбора цели отправляются через штатные операции игры. В сетевой партии у всех участников должна быть одинаковая версия Better Balance Civer. Работа с оригинальным модом дорог одновременно не поддерживается.

## Проверка

`tests/test_auto_roads.lua` исполняет реальные оба Lua-файла с имитацией API игры. Проверены один соседний переход за ход, запрет дальнего шага и объезда к соседу, повторные события без дополнительного расхода ресурсов, продолжение цели, перезагрузка скрипта, заполнение начальной клетки, завершение, отмена, нехватка ресурсов и технологии. Lua-синтаксис и XML проверены.

Это не тест движка Civ VI: в игре ещё нужно подтвердить захват клика по карте, отображение подсказки, возобновление после настоящей загрузки сохранения, длинные маршруты вокруг препятствий и мультиплеер.

## Почему изменена прежняя реализация

Списание движения из UnitMoved не остановило уже выполняемый длинный маршрут. Версия v2 ограничивала только постройку первой клеткой и могла оставлять разрывы — она заменена. Версия v3 вообще не отправляет дальние приказы: только один разрешённый соседний шаг. Движение не ограничивается одним очком до приказа, чтобы не блокировать законный шаг на дорогой рельеф.

Исправление выбора цели: область захвата размером с экран, модальный ввод, выбор левой и правой кнопкой мыши, отмена через Escape. Проверено с имитацией интерфейсного API. Работа с настоящим CQUI требует проверки в игре.

## Журнал и запуск теста

Обновление включено в [общий журнал изменений](../../CHANGELOG.md). Из корня репозитория тест запускается командой `lua tests/test_auto_roads.lua` с Lua 5.4.

После вылета 08.11.2026 зафиксирован нативный SIGABRT в потоке TBB. В отчёте нет прямого указания на Lua или автопрокладку, причинная связь не установлена. Требуется контрольное сравнение одного сохранения с маршрутами и без них. Факт прохождения имитационного теста не подтверждает устранение вылета.
